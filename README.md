
### KiCad PCB and CAD Project

## About

SCREEN is a custom PCB and CAD project designed in KiCad. This
repository contains project files and related CAD exports for reviewing
and developing the design.

## Project Details

-   Designed using KiCad
-   PCB layout and CAD design files
-   Display-focused electronics project
-   CAD exports for viewing and sharing

## Files

The repository may contain KiCad project files, PCB layouts, schematics,
and CAD exports. Download and extract any ZIP archive before opening its
contents.

## Opening the Project

1.  Download the project files from this repository.
2.  Extract the ZIP archive if necessary.
3.  Open the included project in KiCad.
4.  Review the schematic and PCB layout.

## Design Checks

Before manufacturing, verify component footprints, pin assignments,
clearances, board dimensions, and power connections. Run KiCad's
Electrical Rules Checker (ERC) and Design Rules Checker (DRC).
